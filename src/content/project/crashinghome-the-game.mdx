# Overview

CrashingHome is a narrative-driven 2D platformer exploring themes of displacement, memory, and recovery.

As co-creator and designer working alongside an independent developer, I led the narrative worldbuilding, visual identity, and user experience framework for the game.

# The Hiccup

Translating traditional product UX methodologies into game design presented unfamiliar structural challenges, particularly in balancing player agency with linear narrative progression.

We needed a gameplay flow and minimal heads-up display that informed the player without breaking immersion or relying on heavy technological visual tropes.

# The Idea

A moody, hand-drawn alien ecosystem that emphasizes biological overgrowth rather than mechanical futurism.

Player feedback loops, health states, and inventory interactions are mapped directly into contextual, diegetic interface elements that support the central storyline of the protagonist, Lumen.

# The Process

I conducted structural studies of established titles like Hollow Knight to analyze level pacing, screen states, and interaction ergonomics.

From there, I mapped complete screen transitions, drafted environmental concept art, compiled visual moodboards, and prototyped user interface wireframes for the core navigation loop.

# The Impact

The project produced a cohesive design bible featuring finalized screen architecture, art direction guidelines, and early environmental assets.

The foundational design documentation currently guides active engine implementation and level prototyping.
